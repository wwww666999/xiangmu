# DMUI 系列介绍

DMUI（DM User Interface）是一套专为 Roblox 客户端执行器（Client-side Executor）打造的综合型 UI 框架与基础功能库系列。历经多个版本的迭代，DMUI 已经从一个单纯的界面库，演变为集成了底层数据获取、高频实用功能、组件化 UI 渲染以及插件生态的完整开发套件。

## 项目愿景

在 Roblox 脚本生态中，多数脚本往往受限于粗糙的 UI 交互、单一的语言支持以及无法复用代码的“一次性”开发模式。DMUI 的核心使命，是为所有脚本开发者提供一套**工业级、高内聚、低耦合**的底层规范。通过提供统一的设计语言和模块化的 API，让开发者不再将时间浪费在基础的界面拼装与交互逻辑上，从而打造出更加专业、稳定且易于维护的脚本项目。

## 核心特性

*   **统一的视觉与交互规范**：采用现代化的微动效设计。无论是窗口拖拽、聚焦切换、全屏缩放，还是右键菜单的阴影与缓动，均遵循一致的响应逻辑，并原生兼容 PC 端与移动端的不同操作习惯。
*   **原生多语言引擎**：框架内置全局多语言字典，支持热切换，无需重载界面。涵盖简体中文、繁体中文、英语、日语、西班牙语和葡萄牙语，从根本上解决多地区用户的本地化体验问题。
*   **全场景组件库**：提供高度封装的 UI 组件，包括模板窗口生成器（支持最小化至任务栏）、实时列表滚动条、动态光泽特效、实时通知与历史记录面板，以及标准化的数据表单渲染。
*   **插件化拓展架构**：以主框架为核心，通过暴露 `PluginAPI`，允许开发者基于统一标准快速开发特定游戏或特定场景的扩展模块，打破传统闭源脚本的局限。

## 架构理念：主框架与插件互补

Roblox 平台包含数以万计的不同游戏，每个游戏的服务器架构、反作弊机制和核心玩法都有着极大的差异。如果试图将所有特定游戏的复杂逻辑全部内置在主脚本中，必然会导致代码极度臃肿，且极易因为单一游戏的更新而引发全局崩溃。

因此，DMUI 采用了核心底座与外部插件相结合的架构。主框架负责提供稳定的 UI 渲染、交互拦截、底层数据通信以及通用型的基础功能；而对于主脚本无法原生支持、或需要深度定制特定服务器的功能，均可通过编写独立插件来完美替代。插件可以针对特定环境进行快速迭代，而不必等待框架更新，亦不会影响到主框架的稳定性。
