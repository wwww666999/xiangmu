# DMUI4 API 框架

DMUI4 是一个为 Roblox 客户端执行器（Client-side Executor）设计的现代化、全功能 Lua UI 框架与脚本库。项目采用模块化设计，提供丰富的 UI 组件、全局状态管理、多语言支持以及多种游戏内实用功能。

## 核心特性

*   **多语言系统**：内置基于 `UITranslationsLau()` 的统一翻译字典与 `BindText` 辅助函数，原生支持简体中文、繁体中文、英语、日语、西班牙语和葡萄牙语的无缝热切换。
*   **动态右键菜单**：支持基于按钮绑定的自定义右键菜单，完美适配 PC 端（左键/右键）与移动端（轻点/长按 3 秒），带有滚动、屏幕边缘自适应及多语言动态重绑。
*   **高度定制化 UI 组件**：内置模板窗口（`BuildWinUI`），支持自定义拖拽、全屏、缩放、最小化到任务栏。集成实时列表滚动条及动态光泽特效。
*   **玩家档案系统**：支持输入 UserId 或用户名查询。可获取账户创建时间、年龄、好友、封禁状态、粉丝/关注数等。并在 3D 视口中渲染支持拖拽旋转、缩放的玩家虚拟形象。
*   **通知与历史系统**：支持多位置提示、超时自动关闭、按钮交互。内置独立的通知历史记录窗口，支持持久化保存与动态清理（Keep 机制）。
*   **游戏实用功能集成**：
    *   **统一飞行**：整合标准、载具、移动端、CFrame 四种飞行模式，支持速度动态调节。
    *   **观战系统**：自动跟随目标重生，防视角重置，退出时安全恢复本地视角。
    *   **实时定位**：基于 ViewportFrame 计算目标相对距离与方向，显示 3D 箭头引导。
    *   **对象/玩家选择器**：提供标准化的 UI 供脚本调用以选择游戏内的模型、部件或在线玩家。
